# Python Day 127 - Remove Duplicates from a List

This Python program removes duplicate numbers from a list while keeping the original order of the unique elements.

## Example

Original list:
```text
[10, 20, 10, 30, 20, 40, 30]
```

Output:
```text
[10, 20, 30, 40]
```

## Concepts Used

- Python lists
- `for` loop
- `if` statement
- `not in` operator
- `append()` method

## How It Works

The program creates an empty list called `unique_numbers`. It checks each number in the original list and adds it only if it is not already present in the new list.
